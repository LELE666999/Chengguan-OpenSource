# Third-party notices

External-display DDC transport adapts registry mapping and I2C message handling from [waydabber/m1ddc](https://github.com/waydabber/m1ddc), MIT, revision `04d949794102eb8df01ad3681afff6464a3eede2`, reviewed 2026-10-29. The full notice is retained in Vendor/m1ddc-LICENSE and copied into the app. UUID targeting, strict reply validation, serial access, native modes with timed rollback, gamma controls, scenes and SwiftUI interface are implemented in this project. BetterDisplay UI, executable code and licensed features are not bundled. Optional advanced compatibility controls call the user's separately installed BetterDisplay via its documented command interface; that app must be running with the corresponding feature entitlement. CoreDisplay, DisplayServices and IOAVService entry points are dynamically checked private macOS interfaces and may change across OS releases.

Claude account quota endpoint names, numeric window fields and desktop project-root locations were researched from [CodexBar](https://github.com/steipete/CodexBar) (MIT, reviewed 2026-10-28). The bounded Swift quota client, named Claude-only credential access, Chromium cookie decoder and card layout are independently implemented; no CodexBar executable code or browser-cookie import library is bundled. Credentials remain in memory, redirects are denied, and only numeric usage metadata is cached.

UGREEN NAS monitoring uses an independently implemented Swift client for the UGOS local monitoring protocol. Endpoint names, field paths, RSA password login and two-step verification were researched from [UGreen NAS Monitoring](https://github.com/Tom-Bom-badil/home-assistant_ugreen-nas) (GPL-3.0, reviewed 2026-10-26) and its public device API documentation, with authentication details cross-checked against [ugnas-api](https://github.com/Fracizz/ugnas-api) and [ugos-cli](https://github.com/metaneutrons/ugos-cli). No upstream Python implementation, Home Assistant integration, dashboard or artwork is bundled. The native client does not disable certificate validation, install services on the NAS, or include NAS administration commands.

The NAS hardware and distinct storage-pool PNG icons are AI-generated simplified 3D illustrations based on the user's approved C mockup. They are illustrative, not vendor product photography.
